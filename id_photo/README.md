# صورة رسمية · IDPhoto

برنامج ويندوز بلغة بايثون يحوّل الصورة الشخصية إلى صورة رسمية بمواصفات المستمسكات العراقية:
خلفية بيضاء نقية، رأس وكتفان في المنتصف، إضاءة متساوية، وبشرة طبيعية بلا صبغة صفراء.

## التثبيت

1. افتح صفحة **Releases** في هذا المستودع ونزّل أحدث ملف `IDPhoto-<الإصدار>-Setup.exe`.
2. شغّله واتبع الخطوات (لا يحتاج صلاحيات مدير).
3. يعمل البرنامج بلا إنترنت؛ نموذج إزالة الخلفية مرفق مع ملف التثبيت.

## الاستعمال

1. **فتح صورة** ← تُعالَج تلقائياً وتظهر النتيجة بجانب الأصل.
2. اختر **المقاس**: جواز سفر عراقي 3.5×4.5 سم، أو مستمسكات 4×6 سم، أو 3×4 سم.
3. **حفظ الصورة** (JPEG بدقة 600 نقطة/إنج) أو **ورقة طباعة** 10×15 سم فيها عدة نسخ مع خطوط قصّ.

## ماذا يفعل بالصورة، وماذا لا يفعل

بُني على تعليمات الصورة الرسمية: **الحفاظ على هوية الشخص وملامحه كما هي تماماً**.

| يفعل | لا يفعل |
| --- | --- |
| يزيل الخلفية كلها والأشياء التي فيها ويضع أبيض نقياً `#FFFFFF` | لا يُنعّم البشرة ولا يجمّلها ولا يبيّضها |
| يزيل الصبغة الصفراء/الدافئة: توازن أبيض من الأسطح الرمادية في الصورة، ثم حارس يُرجع لون البشرة إلى المجال الطبيعي | لا يغيّر شكل الوجه أو العينين أو الأنف أو الفم أو الحواجب |
| يوحّد الإضاءة: يصحّح التعريض ويرفع الظلال الواسعة على البشرة فقط (من نسخة شديدة التمويه للإضاءة، فتبقى المسام والشامات كما هي) | لا يلمس الحجاب أو الملابس إلا بتصحيح لون الإضاءة نفسه |
| يعدّل ميلان الرأس بتدوير الصورة كلها، ويوسّط الوجه | لا يغيّر التعبير ولا يضيف أو يحذف أي ملمح |
| يقصّ بالمقاس ويشحذ قليلاً للطباعة | — |

يُنصح بتصوير الشخص أمام جدار فاتح وبإضاءة نهارية، مع فراغ فوق الرأس وظهور الكتفين.

## التحديثات و«ما الجديد»

- رقم الإصدار في `idphoto/version.py`، ويظهر في عنوان النافذة وفي «حول البرنامج» وفي اسم ملف التثبيت وخصائصه.
- يتحقق البرنامج من التحديثات مرة يومياً (يمكن إيقافه من قائمة «مساعدة»). عند وجود إصدار أحدث يعرض ملاحظاته
  ويقدّم «تحديث الآن» فينزّل ملف التثبيت ويشغّله بصمت ثم يعيد فتح البرنامج.
- بعد كل تحديث تظهر نافذة **ما الجديد** مرة واحدة بملاحظات كل الإصدارات الجديدة منذ آخر تشغيل،
  ويمكن فتحها في أي وقت من «مساعدة ← ما الجديد».

### إصدار تحديث جديد

```bash
cd id_photo
python tools/bump_version.py patch "إصلاح كذا" "تحسين كذا"   # أو minor / major
git commit -am "IDPhoto 1.0.1" && git push
```

سير العمل `.github/workflows/id-photo.yml` يبني ملف التثبيت على ويندوز، وعند وجود رقم إصدار جديد ينشره
في Releases بالوسم `idphoto-v<الإصدار>`، فيصل التحديث إلى كل المستخدمين.

## التشغيل والبناء من الكود

```bash
cd id_photo
pip install -r requirements.txt
python main.py                      # ينزّل نموذج إزالة الخلفية (176 ميغابايت) في أول معالجة

pip install pyinstaller
python tools/build.py               # dist/IDPhoto-<الإصدار>-Setup.exe (يتطلب Inno Setup 6 على ويندوز)
```

## المكوّنات

- **U²-Net human segmentation** (رخصة Apache 2.0) لفصل الشخص عن الخلفية، يعمل عبر ONNX Runtime.
- **YuNet** من OpenCV Zoo (رخصة MIT) لكشف الوجه والعينين.
- مرشّح موجَّه (Guided Filter) لحواف الشعر والحجاب، و Inno Setup لملف التثبيت.
