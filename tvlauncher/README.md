# جعفر TV

واجهة رئيسية (Launcher) لأجهزة Google TV و Android TV بأسلوب Apple TV، بالعربية ومن اليمين إلى اليسار.

## ماذا فيها

| الشاشة | ماذا تفعل |
| --- | --- |
| **الرئيسية** | تحية باسم جعفر والساعة، وصف تطبيقاتك المثبّتة بشعاراتها. التطبيق المحدَّد يكبر ويرتفع، ويظهر اسمه في الأعلى. عند النزول إلى الصفوف التالية تختفي المنطقة العلوية لتظهر تطبيقات أكثر. |
| **تفاصيل التطبيق** | اضغط مطوّلاً على «موافق» فوق أي تطبيق: فتح، نقل إلى البداية، معلومات التطبيق، حذف. |
| **مركز التحكم** | اضغط على اسمك في الأعلى أو زر القائمة في جهاز التحكم: الساعة والتاريخ، شاشة التوقف، الشبكة، البحث، الإعدادات، والتحكم بالصوت. |
| **الإعدادات** | قائمة بأسلوب Apple TV تفتح صفحات إعدادات الجهاز: الشبكة، الشاشة والصوت، التطبيقات، جهاز التحكم، التاريخ، اللغة، تسهيلات الاستخدام، الشاشة الرئيسية، حول الجهاز. |

يُحفظ ترتيب التطبيقات: المثبَّتة في البداية أولاً، ثم الأكثر استخداماً.

## السرعة

- مكتوبة بـ Kotlin و Jetpack Compose مباشرة، بلا WebView وبلا مكتبات صور أو أيقونات.
- صور التطبيقات تُرسم مرة واحدة لكل إصدار وتُحفظ في الذاكرة، فالرجوع إلى الشاشة الرئيسية فوري.
- قائمة التطبيقات تُحمَّل في الخلفية، والحركات قصيرة (120–220 ملّي ثانية).
- نسخة الإصدار مضغوطة ومحسَّنة بـ R8، وتتضمن Baseline Profiles لتسريع التشغيل الأول.

## التثبيت

يُبنى ملف `JaaferTV.apk` تلقائياً عبر GitHub Actions (`.github/workflows/tv.yml`) ويُنشر في صفحة Releases بوسم يبدأ بـ `tv-`.

1. على التلفاز ثبّت تطبيق **Downloader** أو **Send Files to TV** من متجر Play.
2. نزّل `JaaferTV.apk` من صفحة Releases وافتحه، واسمح بالتثبيت من مصادر غير معروفة إذا طُلب منك.
3. افتح «جعفر TV» من قائمة التطبيقات.

### جعلها الشاشة الرئيسية

Google TV لا يتيح اختيار شاشة رئيسية أخرى من الإعدادات. من حاسوب على الشبكة نفسها، مع تفعيل «تصحيح أخطاء USB/الشبكة» في خيارات المطوّر:

```bash
adb connect <عنوان-التلفاز>
adb install JaaferTV.apk
adb shell cmd package set-home-activity app.jaafer.tv/.MainActivity
```

على أجهزة Android TV القديمة يكفي الضغط على زر Home واختيار «جعفر TV».

## البناء محلياً

يتطلب JDK 17 و Android SDK (المنصة 35):

```bash
cd tvlauncher
./gradlew assembleRelease
```
