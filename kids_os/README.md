# نجوم ⭐ — نظام تعليمي للأطفال على آيباد ميني (الجيل الأول)

«نجوم» نظام كامل للأطفال يعمل بملء الشاشة على الآيباد: شاشة إقلاع، شاشة قفل بالساعة، شاشة رئيسية بأيقونات،
وتطبيقات تعليمية تفاعلية بالعربية مع نطق صوتي ونجوم وملصقات تشجيعية. يعمل **بدون إنترنت** بعد أول فتح.

مكتوب خصيصاً ليعمل على **iOS 9.3.5** (آخر نظام لآيباد ميني 1)، بلا مكتبات خارجية.

## التنصيب على الآيباد

### الطريقة الأولى (الأسهل): من الإنترنت عبر GitHub Pages

**مرة واحدة فقط على GitHub** (من الحاسوب أو الهاتف):

1. ادمج هذا الفرع في الفرع الرئيسي أو اتركه؛ مهمة **Publish Nujoom kids OS** في تبويب **Actions** تنشر النظام تلقائياً إلى فرع `gh-pages`.
2. افتح المستودع ← **Settings** ← **Pages**.
3. في **Source** اختر **Deploy from a branch**، ثم الفرع **gh-pages** والمجلد **/ (root)**، واضغط **Save**.
4. بعد دقيقة يصبح العنوان جاهزاً:
   **https://jaafer12.github.io/CLAUDE-PLUS/**

**على الآيباد:**

1. افتح **Safari** واكتب العنوان أعلاه. انتظر حتى تظهر شاشة القفل (أول مرة يحتاج إنترنت لتنزيل الملفات وتخزينها).
2. اضغط زر **المشاركة** (المربع مع السهم ⬆️) في الأعلى.
3. اختر **«إضافة إلى الشاشة الرئيسية»** ← سمّها «نجوم» ← **إضافة**.
4. ستظهر أيقونة النجمة على شاشة الآيباد. افتح النظام **من الأيقونة** (لا من Safari) فيعمل بملء الشاشة كنظام مستقل.
5. افتحه مرة وأنت متصل بالإنترنت، وبعدها يعمل **بدون إنترنت** تماماً.

> التحديثات: كلما تغيّر الكود ونُشر، يحدّث الآيباد نسخته تلقائياً عند فتح النظام وهو متصل بالإنترنت.

### الطريقة الثانية: من حاسوب في البيت (بدون GitHub)

يحتاج حاسوباً عليه Python 3 ومتصلاً بنفس شبكة الواي فاي:

```bash
cd kids_os
python3 serve.py
```

سيطبع عنواناً مثل `http://192.168.1.5:8000/` ← افتحه في Safari على الآيباد، ثم أكمل من الخطوة 2 أعلاه
(«إضافة إلى الشاشة الرئيسية»). بعد أول فتح يمكنك إطفاء الحاسوب، فالنظام مخزَّن في الآيباد.

## تحويل الآيباد إلى «جهاز نجوم» فقط (القفل)

ميزة **الوصول الموجَّه (Guided Access)** في iOS تقفل الآيباد على تطبيق واحد، فلا يستطيع الطفل الخروج:

1. **الإعدادات** ← **عام** ← **تسهيلات الاستخدام** ← **الوصول الموجَّه** ← شغّله.
2. **إعدادات رمز الدخول** ← ضع رمزاً سرياً يعرفه الأهل فقط.
3. افتح «نجوم» من أيقونته، ثم اضغط **زر الشاشة الرئيسية ثلاث مرات** بسرعة ← **ابدأ**.
4. للخروج: اضغط الزر ثلاث مرات وأدخل الرمز.

نصائح للآيباد القديم:
- **الصوت العربي**: الإعدادات ← عام ← تسهيلات الاستخدام ← الكلام ← الأصوات ← العربية (ماجد). إذا كان النطق صامتاً تأكد أن مفتاح الصامت الجانبي غير مفعّل.
- اترك النظام هو التطبيق الوحيد المفتوح لسرعة أفضل (ذاكرة الآيباد 512MB).
- لإيقاف النوم التلقائي أثناء اللعب: الإعدادات ← العرض والسطوع ← القفل التلقائي.

## للمطوّرين

```
kids_os/
  index.html          هيكل النظام (إقلاع، قفل، سطح المكتب)
  css/os.css          كل التنسيقات
  js/os.js            النواة: النوافذ، اللمس السريع، الأصوات المولّدة، النطق، النجوم والملصقات، التخزين
  js/app-*.js         كل تطبيق في ملف؛ يسجّل نفسه بـ OS.register({...})
  nujoom.appcache     قائمة الملفات للعمل بلا إنترنت (Application Cache، المدعوم في iOS 9)
  icon.png            أيقونة الشاشة الرئيسية (تُرسم بـ tools/make_icon.py)
  serve.py            خادم محلي يرسل appcache بالنوع الصحيح وببصمة تتغيّر مع الملفات
```

- الكود **ES5 فقط** (`var` و`function`، بلا `let`/`const`/`=>`/قوالب نصية)، وبلا CSS Grid، وبلا رموز تعبيرية أحدث من iOS 9.
- لإضافة تطبيق: أنشئ `js/app-xxx.js` يستدعي `OS.register({ id, name, icon, color, build: function (body, app) { ... return { enter, leave }; }, awards: [...] })`، ثم أضفه إلى `index.html` و`nujoom.appcache`.
- التقدّم محفوظ في `localStorage` بالمفتاح `nujoom_v1`.
