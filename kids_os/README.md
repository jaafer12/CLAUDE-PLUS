# نجوم ⭐ — نظام تعليمي للأطفال على آيباد ميني (الجيل الأول)

«نجوم» نظام كامل للأطفال يعمل بملء الشاشة على الآيباد: شاشة رئيسية ملوّنة بأيقونات، والقرآن الكريم،
وسبورة ذكية، وتجارب علمية تفاعلية بالعربية مع نجوم وملصقات تشجيعية. صامت، ويعمل **بدون إنترنت** بعد أول فتح.
يُبنى كله في **ملف واحد** فيه كل الصور والخط، فلا يضيع شيء على الآيباد.

مكتوب خصيصاً ليعمل على **iOS 9.3.5** (آخر نظام لآيباد ميني 1)، بلا مكتبات خارجية.

## التطبيقات

مصمَّم لعمر **3 – 5 سنوات** (طفل لا يقرأ بعد): صور كبيرة، أزرار بأيقونات، لمسة واحدة لكل شيء،
ولا أسئلة مكتوبة. شرح كل تجربة **للأهل** خلف زر «؟» في أعلى الشاشة.

| التطبيق | ماذا يفعل الطفل |
| --- | --- |
| **القرآن الكريم** | 12 سورة من قصار السور بخط المصحف، يقرؤها الأهل مع الطفل. **اقرأ**: يضغط الطفل على الآية فتتظلّل. **احفظ**: يقرأ من حفظه ويضغط ليظهر الكلمة التالية. مع معنى مبسّط لكل سورة. |
| **الرسم** | ألوان كبيرة وممحاة ومسح. يرسم بحرية أو يتتبّع الأشكال والأرقام والحروف، وزر ✓ يعطيه نجمة إذا أحسن. |
| **الكهرباء** | يضغط المفتاح فيضيء المصباح، ويضع أشياء حقيقية في الدائرة ليرى أيّها يُضيئه. |
| **حالات الماء** | زر النار يسخّن (ثلج ← ماء ← بخار) وزر الثلج يبرّد. |
| **يطفو أم يغرق** | يضغط على صورة فتسقط في الماء وتطفو أو تغرق. |
| **المغناطيس** | يسحب المغناطيس فتلتصق أشياء الحديد. |
| **خلط الألوان** | يضغط لونين فيظهر لون جديد في الوعاء. |
| **نمو النبتة** | يسقيها والشمس مشرقة فتكبر حتى تُزهر؛ بلا شمس لا تكبر. |
| **الضوء والظل** | يحرّك الشمس فيطول الظل ويقصر. |
| **السقوط** | يُفلت كرة وريشة على الأرض وعلى القمر. |
| **دورة الماء** | يضغط الشمس ثم الغيمة: بخار ← غيمة ← مطر ← نهر. |
| **الميزان** | يضع صورتين في الكفّتين فيميل الميزان نحو الأثقل. |
| **نجومي** و**الأهل** | النجوم والملصقات (النجمة في الأعلى)، وإعدادات الأهل المحمية بسؤال ضرب. |

النظام **صامت تماماً**. عند النجاح تظهر علامة ✓ خضراء كبيرة أو نجمة.

### مصدر نص القرآن
النص العثماني (رواية حفص) مأخوذ كما هو من **موسوعة القرآن الكريم** (quranenc.com) عبر حزمة `quran-json`،
ولا تُكتب الآيات يدوياً في الكود. التفاصيل في `tools/data/QURAN_SOURCE.md`. الخط: **Amiri Quran** (رخصة SIL OFL).

## التنصيب على الآيباد

### الطريقة الأولى (الأسهل): من الإنترنت عبر GitHub Pages

**مرة واحدة فقط على GitHub** (من الحاسوب أو الهاتف):

1. ادمج هذا الفرع في الفرع الرئيسي أو اتركه؛ مهمة **Publish Nujoom kids OS** في تبويب **Actions** تنشر النظام تلقائياً إلى فرع `gh-pages`.
2. افتح المستودع ← **Settings** ← **Pages**.
3. في **Source** اختر **Deploy from a branch**، ثم الفرع **gh-pages** والمجلد **/ (root)**، واضغط **Save**.
4. بعد دقيقة يصبح العنوان جاهزاً:
   **https://jaafer12.github.io/CLAUDE-PLUS/**

**على الآيباد:**

1. افتح **Safari** واكتب العنوان أعلاه. انتظر حتى تظهر الشاشة الرئيسية الملوّنة (أول مرة يحتاج إنترنت لتنزيل النظام وتخزينه).
2. اضغط زر **المشاركة** (المربع مع السهم ⬆️) في الأعلى.
3. اختر **«إضافة إلى الشاشة الرئيسية»** ← سمّها «نجوم» ← **إضافة**.
4. ستظهر أيقونة النجمة على شاشة الآيباد. افتح النظام **من الأيقونة** (لا من Safari) فيعمل بملء الشاشة كنظام مستقل.
5. افتحه مرة وأنت متصل بالإنترنت، وبعدها يعمل **بدون إنترنت** تماماً.

> التحديثات: كلما تغيّر الكود ونُشر، يحدّث الآيباد نسخته تلقائياً عند فتح النظام وهو متصل بالإنترنت.

### الطريقة الثانية: من حاسوب في البيت (بدون GitHub)

يحتاج حاسوباً عليه Python 3 ومتصلاً بنفس شبكة الواي فاي:

```bash
cd kids_os
python3 serve.py
```

سيطبع عنواناً مثل `http://192.168.1.5:8000/` ← افتحه في Safari على الآيباد، ثم أكمل من الخطوة 2 أعلاه
(«إضافة إلى الشاشة الرئيسية»). بعد أول فتح يمكنك إطفاء الحاسوب، فالنظام مخزَّن في الآيباد.

## تحويل الآيباد إلى «جهاز نجوم» فقط (القفل)

ميزة **الوصول الموجَّه (Guided Access)** في iOS تقفل الآيباد على تطبيق واحد، فلا يستطيع الطفل الخروج:

1. **الإعدادات** ← **عام** ← **تسهيلات الاستخدام** ← **الوصول الموجَّه** ← شغّله.
2. **إعدادات رمز الدخول** ← ضع رمزاً سرياً يعرفه الأهل فقط.
3. افتح «نجوم» من أيقونته، ثم اضغط **زر الشاشة الرئيسية ثلاث مرات** بسرعة ← **ابدأ**.
4. للخروج: اضغط الزر ثلاث مرات وأدخل الرمز.

نصائح للآيباد القديم:
- اترك النظام هو التطبيق الوحيد المفتوح لسرعة أفضل (ذاكرة الآيباد 512MB).
- لإيقاف النوم التلقائي أثناء اللعب: الإعدادات ← العرض والسطوع ← القفل التلقائي.

## للمطوّرين

```
kids_os/
  index.html, css/, js/   مصدر النظام (ملفات منفصلة لسهولة التعديل)
  js/icons.js             أيقونات مرسومة (بدل الرموز التعبيرية التي تظهر صغيرة جداً في iOS 9)
  js/app-*.js             كل تطبيق في ملف؛ يسجّل نفسه بـ OS.register({...})
  tools/build.py          يبني dist/index.html: ملف واحد فيه كل الصور والخط والأكواد
  tools/data/             نص قصار السور ومصدره
  img/, fonts/            الصور الحقيقية (ويكيميديا) وخط المصحف
  serve.py                يبني ثم يشغّل النظام لآيباد على نفس الواي فاي
```

- الكود **ES5 فقط** وبلا CSS Grid ليعمل على Safari 9.
- لإضافة تطبيق: أنشئ `js/app-xxx.js` يستدعي `OS.register({ id, name, icon, color, shade, build, awards })` وأضفه إلى `index.html`.
- التقدّم محفوظ في `localStorage` بالمفتاح `nujoom_v1`.
