# طبيب الحاسبة · PCDoctor

برنامج ويندوز بلغة بايثون يفحص الحاسبة فحصاً كاملاً، ويشرح كل مشكلة بلغة بسيطة، ويصلحها بضغطة.
واجهة عربية حديثة بمظهر داكن وفاتح، مع رقم إصدار وتحديث تلقائي ونافذة «ما الجديد».

## التثبيت

1. افتح صفحة **Releases** في هذا المستودع ونزّل أحدث ملف `PCDoctor-<الإصدار>-Setup.exe`.
2. شغّله واتبع الخطوات (لا يحتاج صلاحيات مدير). يضع أيقونة على سطح المكتب وفي قائمة ابدأ.
3. بعض الإصلاحات تحتاج صلاحيات المسؤول؛ اضغط «تشغيل كمسؤول» في أسفل الشريط الجانبي عند الحاجة.

## الواجهة

| الصفحة | ماذا فيها |
| --- | --- |
| **الرئيسية** | نتيجة صحة الجهاز من 100، وزرّا «فحص سريع» و«فحص شامل»، ومؤشرات حيّة للمعالج والذاكرة والقرص والشبكة، وحالة كل قسم |
| **نتائج الفحص** | بطاقة لكل فحص بلونها (سليم / تنبيه / خطأ)، و«التفاصيل» مع نصيحة، وزر إصلاح لكل مشكلة، و«إصلاح الكل»، وتصفية «المشكلات فقط» |
| **معلومات الجهاز** | النظام والمعالج والذاكرة وكرت الشاشة واللوحة الأم والأقراص والبطارية، مع زر نسخ |
| **سجلّ الفحوص** | الفحوص السابقة ونتائجها والإصلاحات التي نُفِّذت |
| **الإعدادات** | المظهر، نقطة الاستعادة، الفحص عند الفتح، التحديث التلقائي، ما الجديد |

**الأمان أولاً:** قبل أول إصلاح يغيّر إعدادات ويندوز يُنشئ البرنامج **نقطة استعادة للنظام** (يمكن إيقافه من الإعدادات).
الإصلاحات التي قد تؤثر على عملك (إعادة التشغيل، ملف hosts، الخادم الوسيط) لا تدخل في «إصلاح الكل» وتطلب تأكيداً.
البرنامج لا يحذف أي ملف من ملفاتك الشخصية، ولا يغيّر تعريفات أو برامج دون علمك.

## التحديثات و«ما الجديد»

- رقم الإصدار في `pcdoctor/version.py`، ويظهر في عنوان النافذة والشريط الجانبي والإعدادات واسم ملف التثبيت وخصائصه.
- يتحقق البرنامج من التحديثات مرة يومياً. عند وجود إصدار أحدث يعرض ملاحظاته ويقدّم «تحديث الآن»
  فينزّل ملف التثبيت ويشغّله بصمت ثم يعيد فتح البرنامج.
- بعد كل تحديث تظهر نافذة **ما الجديد** مرة واحدة بملاحظات الإصدارات الجديدة، ويمكن فتحها من الإعدادات.

### إصدار تحديث جديد

```bash
cd pc_doctor
python tools/bump_version.py patch "إصلاح كذا" "تحسين كذا"   # أو minor / major
git commit -am "PCDoctor 1.0.1" && git push
```

سير العمل `.github/workflows/pc-doctor.yml` يشغّل كل الفحوص على ويندوز للتأكد من أنها تعمل، ثم يبني ملف التثبيت،
وعند وجود رقم إصدار جديد ينشره في Releases بالوسم `pcdoctor-v<الإصدار>`، فيصل التحديث إلى كل المستخدمين.

## التشغيل والبناء من الكود

```bash
cd pc_doctor
pip install -r requirements.txt
python main.py                      # أو: python main.py --scan
python tools/selftest.py            # يشغّل كل الفحوص في الطرفية دون إصلاح

pip install pyinstaller
python tools/build.py               # dist/PCDoctor-<الإصدار>-Setup.exe (يتطلب Inno Setup 6 على ويندوز)
```

## المكوّنات

- **CustomTkinter** (رخصة MIT) للواجهة، و **psutil** (رخصة BSD) لقراءة الأداء والأقراص والبطارية.
- أوامر ويندوز المدمجة: PowerShell (Defender، جدار الحماية، الخدمات، الأقراص، سجلّ الأحداث)، DISM، SFC، pnputil، powercfg.
- Inno Setup لملف التثبيت، و PyInstaller لتجميع البرنامج.
