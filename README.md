# كلمة كلمة · Kalima Kalima

تطبيق أندرويد لتعلّم اللغة الإنكليزية، مصمَّم لمن يعاني من عُسر القراءة (الديسلكسيا)، وخصوصاً صعوبة قراءة الكلمات الطويلة.
الواجهة بالعربية، وكل كلمة إنكليزية تظهر مقسّمة إلى مقاطع ملوّنة: `beau·ti·ful`.

## التثبيت على الهاتف

1. افتح صفحة **Releases** في هذا المستودع من هاتفك، أو هذا الرابط مباشرة:
   `https://github.com/jaafer12/CLAUDE-PLUS/releases/latest/download/KalimaKalima.apk`
2. نزّل الملف `KalimaKalima.apk` وافتحه.
3. إذا طلب الهاتف ذلك، اسمح للمتصفح بتثبيت التطبيقات من مصادر غير معروفة، ثم اضغط «تثبيت».

يُبنى ملف APK تلقائياً عبر GitHub Actions بعد كل تحديث للكود (`.github/workflows/android.yml`).

> النطق: الكلمات والجمل والقصص مسجّلة بصوت طبيعي من نموذج **Kokoro** المفتوح المصدر (رخصة Apache 2.0، الصوت af_heart)، يُولَّد تلقائياً على GitHub Actions عبر `tools/gen_voice_kokoro.py` بلا مفتاح ولا تكلفة. أي نص غير مسجّل (مثل نصوص القارئ) يُقرأ بمحرك النطق في الهاتف.
> للنطق في الهاتف، إذا لم تسمع صوتاً، ثبّت أو حدّث «خدمات Google للنطق» (Speech Services by Google) من متجر Play.

## المراجع التي بُني عليها التصميم

- **British Dyslexia Association – Dyslexia Style Guide**: خطوط بلا زوائد، حجم كبير، تباعد أسطر 1.5، تجنّب المائل والتسطير، خلفية غير بيضاء ناصعة.
- **Rello & Bigham (2017), Good Background Colors for Readers, ASSETS**: الخلفيات الدافئة (الخوخي، البرتقالي الفاتح) حسّنت أداء القراءة لدى المصابين بالديسلكسيا؛ لذلك الخلفية الافتراضية خوخية.
- **Zorzi et al. (2012), Extra-large letter spacing improves reading in dyslexia, PNAS**: مسافة أوسع بين الحروف.
- **Rello, Pielot & Marcos (2016), Make It Big!, CHI** و **Rello & Baeza-Yates (2013), Good Fonts for Dyslexia, ASSETS**: خط كبير غير مائل.
- **Lexend** (مشروع Bonnie Shaver-Troup) لخط القراءة الافتراضي، و **Readex Pro** (نسخته العربية) للواجهة.
- **منهج أورتن-جيلينغهام / Structured Literacy (International Dyslexia Association)**: تعليم متعدد الحواس (أرى، أسمع، أقول، ألمس) وتقسيم الكلمات إلى مقاطع.
- **Leitner (1972)** ومنحنى النسيان لإبنغهاوس: المراجعة المتباعدة.
- **Paivio, Dual Coding Theory**: صورة + صوت + كلمة معاً.

## بنية المشروع

```
web/app.html            واجهة التطبيق كاملة (HTML/CSS/JS في ملف واحد، بلا مكتبات)
web/img/                صور الكلمات (webp) و credits.json
web/audio/              مقاطع الصوت (mp3) و voice.json
tools/                  gen_voice.py و embed_voice.py (الأصوات)، images.json (كلمة ← صورة)، fetch_images.py، embed_photos.py
web/fonts/              الخطوط مضمّنة ليعمل التطبيق بلا إنترنت (رخصة SIL OFL)
android/                مشروع أندرويد: WebView + جسر للنطق (TextToSpeech) والتعرّف على الصوت (SpeechRecognizer) والاهتزاز
.github/workflows/      بناء ملف APK ونشره في Releases
```

مهمة `bundleWeb` في `android/app/build.gradle.kts` تأخذ `web/app.html` وتضعه داخل التطبيق، فيبقى للواجهة مصدر واحد فقط.

### البناء محلياً

يتطلب JDK 17 و Android SDK (المنصة 35):

```bash
cd android
./gradlew assembleDebug
# الناتج: android/app/build/outputs/apk/debug/app-debug.apk
```

ملف التوقيع `android/app/debug.keystore` مفتاح تجريبي عام (كلمة السر `android`). وُضع في المستودع حتى تُحدِّث كل نسخة جديدة التطبيقَ المثبّت دون حذفه. لا تستخدمه لنشر التطبيق على متجر Play.

لتحرير الكلمات أو إضافة دروس: عدّل مصفوفة `RAW` في أعلى الـ script داخل `web/app.html`. كل سطر بالشكل:

```
word|syl·la·bles|المعنى|النطق·بالعربي|🖼️|Example sentence.|ترجمة الجملة.
```

### توليد الأصوات

تعمل مهمة **Record voices** (`.github/workflows/voice.yml`) تلقائياً: تسجّل المقاطع الناقصة بـ Kokoro، وتضيفها إلى `web/app.html`، ثم تعيد بناء ملف APK. لتسجيل كلمات أو قصص جديدة بعد تعديلها، شغّل المهمة يدوياً من تبويب Actions.

بديل اختياري بأصوات Google (يحتاج مفتاح Gemini مع تفعيل الدفع):

```bash
export GEMINI_API_KEY=...        # لا تضعه في أي ملف داخل المستودع
python3 tools/gen_voice.py && python3 tools/embed_voice.py
```
